# Games

## ⭐ 소이랑 준이의 별 & 🎂 케이크 놀이 (`sohee-star-cake/`)
5살 소이와 준이를 위한 터치 게임. 휴대폰·태블릿·PC 모두 브라우저에서 바로 플레이.

- **별 찾기**: 반짝이는 별 10개를 찾기. 리온이에게 잡히면 귀여운 💩!
- **케이크 만들기**: 핑 친구가 보여준 케이크대로 색을 쌓기. 틀리면 리온이가 달려와 💩!
- **리온이 먹이기**: 소이가 만든 케이크를 눌러 리온이에게 먹이기. 배가 빵빵해지면 뿌지지직 💩! 똥을 눌러 치우기
- **모기 잡기**: 빠르게 날아다니는 모기 20마리 잡기. 다이아나핑·하츄핑·오로라핑이 섞여 날아다니니 핑은 잡으면 안 돼요! 누르면 소이가 손바닥으로 탁! 가끔 리온이가 깨어나 도와줘요. 모기에 물리면 리온이가 깜짝 놀라 💩!
- **공주님 꾸미기**: 은율 인어공주(꼬리 색 바꾸기), 엘사, 무지개 괴물, 신데렐라에게 왕관·목걸이·꽃·요술봉·반짝이·나비·하트를 씌워주고 ✨변신! 그러면 리온이가 와서 방구 뿡!
- **무지개 괴물 치과**: 은율 선생님과 함께 무지개 괴물 이빨 치료! 🦠세균은 🪥칫솔로, 💩충치 똥은 💧물총으로. 다 고치면 엘사·신데렐라가 축하하러 와요
- **악어 괴물 물리치기**: 토끼를 잡아먹는 악어 괴물! 토끼를 눌러 집으로 구해주고, 하츄핑(하트 빔)·다이아나핑(별 공격)·오로라핑(무지개 간지럼)·이클립스핑(잠자는 달빛) 마법으로 악어 배 속 토끼를 꺼억! 꺼내기. 리온이 방구 공격도! 악어 3형제(악어 괴물 → 불꽃 악어 → 왕 악어) 3단계, 황금 토끼, 당근 미끼, ⭐티니핑 합체 마법
- 리온이가 똥 쌀 때마다 여러 가지 웃긴 방구 소리, 신나는 배경음악 (🎵 버튼으로 끄고 켜기)
- 한국어 음성 안내 (소리를 켜주세요)

### 플레이
`sohee-star-cake/index.html` 파일 하나만 열면 됩니다 (이미지 포함, 인터넷 불필요).

### 수정하기
`game.src.html`을 고친 뒤 `python3 build.py` (Pillow 필요)로 `index.html`을 다시 만듭니다.

# Games

## ⚔️ 소이랑 준이의 무지개 마을 대모험 (RPG)
용사(🪄 별빛 마법사 소이 / 🛡️ 꼬마 기사 준이)를 고르면 리온이와 함께 마을을 걸어다니며 13명의 친구를 도와요. 각 놀이가 퀘스트이고, 완료하면 🏅 배지와 EXP, 레벨업! 배지 13개를 모으면 신데렐라 성 무도회 엔딩.

## ⭐ 소이랑 준이의 별 & 🎂 케이크 놀이 (`sohee-star-cake/`)
5살 소이와 준이를 위한 터치 게임. 휴대폰·태블릿·PC 모두 브라우저에서 바로 플레이.

- **별 찾기**: 반짝이는 별 10개를 찾기. 리온이에게 잡히면 귀여운 💩!
- **케이크 만들기**: 핑 친구가 보여준 케이크대로 색을 쌓기. 틀리면 리온이가 달려와 💩!
- **리온이 먹이기**: 소이가 만든 케이크를 눌러 리온이에게 먹이기. 배가 빵빵해지면 뿌지지직 💩! 똥을 눌러 치우기
- **모기 잡기**: 빠르게 날아다니는 모기 20마리 잡기. 다이아나핑·하츄핑·오로라핑이 섞여 날아다니니 핑은 잡으면 안 돼요! 누르면 소이가 손바닥으로 탁! 가끔 리온이가 깨어나 도와줘요. 모기에 물리면 리온이가 깜짝 놀라 💩!
- **공주님 꾸미기**: 은율 인어공주(꼬리 색 바꾸기), 엘사, 무지개 괴물, 신데렐라에게 왕관·목걸이·꽃·요술봉·반짝이·나비·하트를 씌워주고 ✨변신! 그러면 리온이가 와서 방구 뿡!
- **무지개 괴물 치과**: 은율 선생님과 함께 무지개 괴물 이빨 치료! 🦠세균은 🪥칫솔로, 💩충치 똥은 💧물총으로. 다 고치면 엘사·신데렐라가 축하하러 와요
- **악어 괴물 물리치기**: 토끼를 잡아먹는 악어 괴물! 토끼를 눌러 집으로 구해주고, 하츄핑(하트 빔)·다이아나핑(별 공격)·오로라핑(무지개 간지럼)·이클립스핑(잠자는 달빛) 마법으로 악어 배 속 토끼를 꺼억! 꺼내기. 리온이 방구 공격도! 악어 3형제(악어 괴물 → 불꽃 악어 → 왕 악어) 3단계, 황금 토끼, 당근 미끼, ⭐티니핑 합체 마법
- **영어 숫자 놀이**: 리온이가 던지는 공을 소이·준이가 받으며 One, Two, Three! 영어 발음으로 1~10 세기, 10칸 상자로 수 개념, "How many?" 맞히기
- **새 그래픽**: 소이·준이(한복·조끼 몸), 꼬리 흔드는 리온이, 사람 비율의 은율 인어공주로 모든 놀이 통일
- **인어공주 바다 모험**: 은율 인어공주가 리온이·괴물·늑대를 피해 헤엄! 하츄핑(하트 방패)·오로라핑(무지개 부스터)·다이아나핑(별 자석)·이클립스핑(달빛 마법)이 도와줘요. 🦈상어(⚡대시)/🐋고래(💦물뿜기)를 타고 엘사·신데렐라와 레이싱
- **👸 소이 공주 퍼레이드 꾸미기**: 소이 얼굴 + 그림 몸 종이인형. 드레스 10종(+색 바꾸기), 왕관 7종, 목걸이, 손에 들기(요술봉·풍선·꽃다발…), 구두, 장갑, 날개·망토, 머리, 얼굴 스티커, 마법 효과, 배경. 🎲 깜짝 변신, 🎉 퍼레이드 마차 쇼와 📸 사진 모드
- **🏁 매직 퍼레이드 그랑프리 (진짜 3D, three.js)**: 3D 마차·관람차·롤러코스터·회전목마·성·불꽃놀이·별하늘, 체이스 카메라. three.js를 못 불러오면 유사 3D로 자동 전환. 언덕·커브가 있는 퍼레이드 코스 3바퀴, 7대 레이스(꼴찌 출발). 💨 드리프트 미니 터보(파랑→주황→분홍), 🚀 로켓 스타트, ⭐ 별 코인(최대 10개, 속도 업), 순위별 아이템(🦄 유니콘 돌진·트리플 부스터 등), 👊 펀치, 🥤 미끄럼 함정, 똑똑하게 반격하는 라이벌
- **❄️ 엘사의 노래와 동화책**: 얼음 성 문이 열리고 엘사 등장 → 직접 작사·작곡한 「티니핑 친구들」 노래(가라오케 가사, 티니핑·소이·준이·리온이 댄스, 눌러서 악기 연주) → 오르골 배경음과 함께 엘사가 읽어주는 동화책 「엘사와 사라진 마법 별」(7쪽, 문장 하이라이트, 그림 눌러 대사)
- **🎅 산타·루돌프 보물찾기 & 생일파티**: 눈숲에서 루돌프 빨간 코(가까울수록 반짝·삐삐 소리)로 보물을 찾아 리온이보다 먼저 4개! → 생일 주인공 고르기, 초 꽂기(숫자 세기), 생일 축하 노래(가라오케), 촛불 후~ 불기, 보물 선물 열기. 엘사·신데렐라·산타·루돌프가 함께 축하
- 리온이가 똥 쌀 때마다 여러 가지 웃긴 방구 소리, 신나는 배경음악 (🎵 버튼으로 끄고 켜기)
- 한국어 음성 안내 (소리를 켜주세요)
